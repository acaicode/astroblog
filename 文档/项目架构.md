# 项目层次说明

这个项目是一个 Astro v6 多语言博客。Markdown 文章放在内容集合里，由动态路由读取，再交给布局组件渲染成具体页面。

## 博客详情页在哪里

Markdown 文章详情页入口是：

```text
src/pages/[...locale]/posts/[...slug].astro
```

它负责：

- 从 `src/content/posts/<locale>/...` 读取文章。
- 为每篇文章生成静态路径。
- 调用 `render(post)` 把 Markdown / MDX 转成 Astro 内容组件。
- 把文章内容、目录 headings、上一篇/下一篇等数据传给文章布局。

真正决定文章页结构和评论区位置的是：

```text
src/layouts/PostLayout.astro
```

文章详情页的渲染链路是：

```text
src/content/posts/en/foo.md
        ↓
src/pages/[...locale]/posts/[...slug].astro
        ↓
src/layouts/PostLayout.astro
        ↓
src/layouts/BaseLayout.astro
        ↓
浏览器页面
```

## 评论系统

项目现在只使用 Twikoo 作为评论系统。

评论组件在：

```text
src/components/Twikoo.astro
```

文章页通过 `src/layouts/PostLayout.astro` 引入：

```astro
import Twikoo from '../components/Twikoo.astro';
import { SITE, TWIKOO, type Locale } from '../config';
```

文章底部的评论显示逻辑是：

```ts
const commentsEnabled = post.data.comments !== false && TWIKOO.enabled;
```

也就是说：

- 全局开关由 `src/config.ts` 里的 `TWIKOO.enabled` 控制。
- Twikoo 后端地址由 `src/config.ts` 里的 `TWIKOO.envId` 控制。
- 单篇文章可以在 frontmatter 写 `comments: false` 来关闭评论。

Twikoo 配置位置：

```ts
export const TWIKOO = {
  enabled: true,
  envId: 'https://cf-create-worker.2560001677zyb.workers.dev',
  elementId: 'tcomment',
  lang: 'zh-CN',
  version: '1.7.9',
};
```

以后如果要改 Twikoo 后端地址、语言、客户端版本或全局开关，优先改 `src/config.ts`，不用改组件源码。

## Markdown 内容在哪里

文章内容放在：

```text
src/content/posts/
```

当前示例：

```text
src/content/posts/en/getting-started.md
src/content/posts/fr/getting-started.md
```

普通页面内容放在：

```text
src/content/pages/
```

例如：

```text
src/content/pages/en/about.md
src/content/pages/en/privacy.md
src/content/pages/fr/about.md
src/content/pages/fr/privacy.md
```

内容集合的 frontmatter schema 在：

```text
src/content.config.ts
```

常用字段包括：

- `title`
- `description`
- `pubDate`
- `updatedDate`
- `tags`
- `categories`
- `draft`
- `heroImage`
- `comments`
- `toc`
- `math`
- `translationKey`

## 页面路由层

Astro 页面路由都在：

```text
src/pages/
```

主要页面：

```text
src/pages/[...locale]/index.astro                  首页 / 文章列表
src/pages/[...locale]/posts/[...slug].astro        文章详情页
src/pages/[...locale]/categories/index.astro       分类列表
src/pages/[...locale]/categories/[category].astro  某个分类下的文章
src/pages/[...locale]/tags/index.astro             标签列表
src/pages/[...locale]/tags/[tag].astro             某个标签下的文章
src/pages/[...locale]/archives.astro               归档
src/pages/[...locale]/about.astro                  关于页
src/pages/[...locale]/privacy.astro                隐私页
src/pages/[...locale]/search.astro                 搜索页
src/pages/[...locale]/rss.xml.ts                   RSS
src/pages/404.astro                                404 页面
src/pages/og/[...slug].png.ts                      自动生成 Open Graph 图片
```

`[...locale]` 是可选语言前缀。默认语言没有前缀，非默认语言会带上语言路径，例如 `/fr/...`。

## 布局层

布局文件在：

```text
src/layouts/
```

主要职责：

```text
src/layouts/BaseLayout.astro  全站外壳：HTML、SEO、侧边栏、顶部栏、右侧面板、页脚
src/layouts/PostLayout.astro  博客文章页布局：标题、日期、正文、标签、上一篇/下一篇、Twikoo 评论
src/layouts/PageLayout.astro  普通 Markdown 页面布局：关于页、隐私页等
```


## 工具函数层

工具函数放在：

```text
src/utils/
```

主要文件：

```text
src/utils/posts.ts          文章读取、排序、slug、标签/分类路径、翻译文章匹配
src/utils/reading-time.ts   阅读时间估算
src/utils/seo.ts            SEO 数据构建
src/utils/og-image.ts       OG 图片生成辅助
```

其中 `src/utils/posts.ts` 很关键，文章列表页、详情页、分类页、标签页都会用它。

## 国际化层

国际化相关文件在：

```text
src/i18n/
```

主要文件：

```text
src/i18n/ui.ts      文案字典
src/i18n/utils.ts   locale 检测、路径处理、日期格式化、翻译函数
src/i18n/index.ts   i18n 统一导出
```

支持哪些语言，由 `src/config.ts` 中的 `locales` 和 `SITE.defaultLocale` 控制。

## 全局配置

主要配置文件：

```text
src/config.ts       站点标题、作者、导航、社交链接、Twikoo、Pagefind 等配置
astro.config.mjs    Astro、Markdown、MDX、图片、插件、集成配置
package.json        脚本和依赖
.env                本地环境变量，主要用于站点 URL、GitHub Pages base path 等
```

想改站点名称、作者、导航、评论开关，通常先看 `src/config.ts`。

## 样式和资源

全局样式在：

```text
src/styles/global.css
```

站点内置资源在：

```text
src/assets/
```

公共静态资源在：

```text
public/
```

这里的文件会原样复制到最终站点根路径，例如 `robots.txt`、RSS 样式、sitemap 样式。

## 常用开发命令

```bash
npm run dev
npm run build
npm run preview
npm run typecheck
npm run lint
```

注意：当前 `npm run build` 脚本最后会调用 `bun run pagefind`。如果本机没有安装 Bun，Astro 构建能成功，但 build 命令会在 Pagefind 那一步失败。

## 修改评论功能的推荐顺序

1. 打开 `src/config.ts`。
2. 修改 `TWIKOO.enabled` 控制全站评论开关。
3. 修改 `TWIKOO.envId` 控制 Twikoo 后端地址。
4. 如果只想关闭某一篇文章，在对应 Markdown frontmatter 写：

```yaml
comments: false
```
